# 糯米的小屋：居中茶几与正向行走

本版保留猫咪大小、原始模型、绑定、贴图和全部动作。茶几的水平中心与地毯中心对齐，花瓶和四季桌面摆件一起移动。

## 运行

- OhMyGame：导入项目 ZIP，使用静态网页预览，入口为 `/`。
- 普通浏览器：在项目目录执行 `node tools/serve.mjs`，打开 `http://127.0.0.1:8770/`。无需安装依赖。
- 点击空地移动；点击猫咪、食碗、小球或家具互动。双指开合缩放，双指拖动旋转。

## 活动范围修正

- 点击后先看向目标，再切换站立姿态、转动身体，对齐方向后才向前走。转身期间不推进走路周期。
- 途中重新点击会停下并重新转头；取消倒退、侧滑和走路动画倒放。
- 路径使用 16 个方向，并检查整个转身过程。点击地面时也检查离开路线，避免走进无法转身的死角。
- 茶几保持地毯正中；沙发连同靠垫略后移，小落地灯与书盘靠墙，为桌边转向留出空间。
- 桌面、桌腿和不同高度的障碍分别计算，不再使用一整块立方体封闭桌子周围。
- 身体与尾巴使用独立范围。窄处先调整尾巴再移动；有足够空间时恢复原始摆尾。
- 保留原始动画文件；尾巴调整仅作用于运行时骨骼，不修改蒙皮或贴图。
- 临近障碍的地面点击会寻找 0.42 场景单位内可到达的站位，不会瞬移。
- 桌子四侧、各互动点的往返路线和低帧率下的移动均有自动检查。

`tuning.json` 可调整镜头范围与步速，不影响模型尺寸和碰撞体。
